# iPhone用・獣医腫瘍認定医問題集

このフォルダは、Safariからホーム画面に追加して使う個人用学習アプリです。App Storeへの申請は不要です。

## できること

- 502問からランダムに10問を学習
- 分野・難易度を選んで出題
- 30問・50問・100問の模擬試験（基本40%、標準40%、難問20%）
- 解答直後の根拠・選択肢別解説・教科書ページ表示
- 間違えた問題と「あとで復習」したい問題の保存
- 初回読込後の端末内保存

## iPhoneでの使い始め方

このアプリはWeb上に置いてから使います。公開先は、静的なWebサイトを公開できるサービス（GitHub Pages、Cloudflare Pages、Netlifyなど）を利用してください。

公開するときは、`problem_bank` フォルダ全体を同じ階層構成のまま配置します。特に `questions.json` と `iphone_app` フォルダの位置関係を変えないでください。

公開後、iPhoneのSafariで `iphone_app` のURLを開きます。共有ボタンから **「ホーム画面に追加」** を選ぶと、ホーム画面のアイコンから起動できるようになります。

初回は通信できる環境で開いてください。問題データと学習記録は端末内に保存されるため、その後は通信が不安定な場面でも継続して使えます。Safariの閲覧データを消去すると、端末に保存した解答履歴・復習リストは消えます。

## ファイル

- `index.html`：アプリの入口
- `app.js`：出題、採点、復習、模試の処理
- `styles.css`：iPhone向け画面デザイン
- `manifest.webmanifest` / `sw.js`：ホーム画面追加・オフライン利用の設定

問題本文の正本は親フォルダの `questions.json` です。問題を編集・追加すると、公開先の同ファイルを更新すればアプリへ反映されます。
